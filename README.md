# BB Experience Launcher & KEY2 Keyboard (v2.0)

### Features Built-In:
1. **BB OS7 & BB10 Themes + Wallpapers:** Translucent status banner, switchable BB OS7 grid / BB10 card layouts, scrubbable page dots, and bottom dock.
2. **First-Run Companion Suite Installer Prompt:** Automatically detects and prompts to install BlackBerry Hub+ Services, BlackBerry Hub, BlackBerry Calendar, and BlackBerry Notes.
3. **Resizable KEY2 Keyboard:** Live drag handle and settings slider (`75% - 135%`).
4. **Flow / Glide Typing:** Swipe across keys (e.g. `e -> f -> d` -> `end`) with spatial path scoring and Gboard-style swipe-up candidates.
5. **Customizable Home Screen & App Drawer:** Allow or remove individual apps from the home screen via Settings.
6. **Right-Edge Slider Tab (Productivity DOC):** Slide out quick tools from anywhere.
7. **Speed Key (`:::`) Shortcut Customizer:** Bind any letter key to launch your chosen productivity app.
8. **App Drawer Launcher Icon:** Installs a **BB Experience Setup** icon in your app drawer so you can always open settings and change your default home screen.
