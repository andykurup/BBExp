# BB Experience Launcher & KEY2 Keyboard (v1.1)

Includes:
- **3:2 Aspect Ratio Viewport:** Strict 1.5:1 top display emulation.
- **Productivity Whitelist:** Automatically hides games and social media feeds.
- **System-Wide KEY2 Keyboard (`BBKeyboardService`):**
  - Gboard-style prediction bar with BlackBerry **swipe-up (flick) to select** gestures.
  - **Spacebar long-press** trackpad cursor scrolling.
  - **Physical-grade Haptics (`BBVibrator`)** using Android `VibrationEffect` clicks and trackpad ticks.
  - **Speed Key (`:::`)** app quick-launch shortcuts.
  - **Emoji & Symbol matrix**.

### Build on GitHub Actions
Push this repository to `https://github.com/andykurup/BBExp.git` (`main` branch). The workflow in `.github/workflows/build.yml` will automatically compile `app-debug.apk` under the **Actions** tab.
