# BB Experience Launcher & KEY2 Keyboard (v2.2)

### Updates in v2.2:
1. **All Installed Apps Included (Social Media & Utilities):** Every app on your device appears in the **Apps** drawer and in **Settings → Allow / Remove Apps on Home Screen**. Social media and games start toggled OFF on the Home Screen for a clean productivity setup, and you can toggle any of them ON whenever you want.
2. **Adaptive Full-Screen Layout:** Zero black gap between the home screen and keyboard.
3. **Gboard-Style Live Predictions & Flow Swipe Typing:** Always displays 3 active word/next-word/emoji suggestions and works system-wide inside external apps.
